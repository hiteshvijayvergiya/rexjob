=====================================
QUICK START
=====================================

1. Extract: unzip rexjobs-nodejs-COMPLETE.zip
2. Navigate: cd rexjobs-nodejs
3. Install: npm install
4. Configure: cp .env.example .env (edit DB settings)
5. Create DB: mysql -u root -p -e "CREATE DATABASE rexjobs;"
6. Migrate: npm run migrate:latest
7. Start: npm run dev
8. Visit: http://localhost:3000
